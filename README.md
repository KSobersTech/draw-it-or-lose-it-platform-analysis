# Draw It or Lose It — Software Design and Platform Analysis

## Project Overview

This portfolio project presents a software design and operating-platform analysis for **Draw It or Lose It**, a game developed by the fictional client **The Gaming Room**. The client wanted to expand an Android-only application into a secure, scalable, web-based system that could support users across desktop and mobile platforms.

## My Role

I approached the project from the perspective of a junior software designer and systems analyst. I reviewed the client requirements, evaluated operating-platform options, analyzed system architecture considerations, and developed a technical recommendation for the proposed application.

## Technical Recommendation

The recommended solution uses a **Linux-based cloud server** for the backend and a **responsive web application** for client access. This approach supports Windows, macOS, Android, iOS, and browser-based users while providing a scalable and cost-effective foundation.

The proposed architecture includes:

- Java-based server-side services
- RESTful communication over HTTPS
- Relational database storage for structured information
- Cloud object storage for images, logs, and backups
- Authentication, authorization, encryption, monitoring, and least-privilege access
- Load balancing, redundancy, and failover planning for future growth
